# Documentación y Manuales de Compra Ágil

Coloca en esta carpeta cualquier archivo `.pdf`, `.txt` o `.md` relacionado con Compra Ágil (manuales oficiales, instructivos, guías o normativas).

El servidor MCP podrá buscar información conceptual dentro de estos archivos para responder tus preguntas utilizando la herramienta `consultar_documentos_locales`.
